# 데모 가이드

## 이 데모가 보여주는 것

이 서비스는 “자산군 카탈로그/역할 정의 -> 후보 종목 관리 -> 역할 기반 컴포넌트 선택 -> Efficient Frontier 계산” 흐름을 설명하는 데모입니다.

사용자는 메인 화면에서:

1. 목표 기대수익률 슬라이더를 움직입니다.
2. 시스템은 active 유니버스의 자산군별 후보 종목군과 역할을 읽습니다.
3. 역할에 따라 포트폴리오 컴포넌트를 구성합니다.
4. 선택된 컴포넌트 유니버스로 Efficient Frontier를 계산합니다.
   이때 계산과 히스토리 차트는 가장 늦게 시작한 종목 기준의 공통 가격 구간만 사용합니다.
5. 화면은 결과를 자산군 비중/리스크 기여도/설명 카드로 보여줍니다.

## 발표할 때 핵심 메시지

- "이 서비스는 종목 추천 서비스가 아니라 포트폴리오 구조를 설명하는 시뮬레이션입니다."
- "관리자가 자산군별 후보 종목과 역할을 정하면, 시스템은 그 역할 정의에 맞는 포트폴리오 컴포넌트를 구성해 최적화를 수행합니다."
- "상관관계는 가격 데이터에서 직접 계산하고, Sharpe Ratio와 함께 고려합니다."
- "화면은 계산 결과를 자산군 기준으로 다시 묶어 설명합니다."

## 시연 순서 추천

### 1. 관리자 콘솔 준비

`/admin`에서 아래를 먼저 보여주면 좋습니다.

- active 유니버스 존재
- 가격 적재 성공
- readiness `계산 가능`
- 자산군 역할 정보 확인 가능

### 2. 메인 시뮬레이터

메인 `/`에서는 아래 순서로 설명하면 자연스럽습니다.

1. 목표 기대수익률 슬라이더
2. Efficient Frontier 차트
3. 현재 포트폴리오 포인트
4. 현재 적용된 컴포넌트 구성
5. 자산군별 비중과 리스크 기여도
6. 설명 카드

## 추천 입력값

현재 메인 화면은 목표 기대수익률 슬라이더 기반이므로, 발표 때는 아래 지점을 추천합니다.

- 안정형: 좌측 20% 부근
- 균형형: 중앙 50% 부근
- 성장형: 우측 80% 부근
- 최대 샤프: 차트의 `최대 샤프` 점 클릭

## 시연 전 체크리스트

- `/health`가 `{"status":"ok"}` 를 반환하는지 확인
- `/admin/universe/status`에서 active 버전이 잡혀 있는지 확인
- `/admin/universe/readiness`에서 `ready=true`인지 확인
- `/admin/prices/status`에서 최근 가격 적재가 성공했는지 확인
- 메인 페이지에서 차트와 카드가 정상 렌더링되는지 확인
- 슬라이더를 움직였을 때 포트폴리오 포인트가 바뀌는지 확인

## 관리자 콘솔 운영 순서

1. 자산군별 후보 종목 입력
2. 유니버스 버전 생성 또는 수정
3. 필요한 버전을 active로 전환
4. 가격 갱신 실행
5. readiness 점검
6. 메인 시뮬레이터에서 결과 확인

## 지금 이 데모를 볼 때 알아야 하는 점

- 계산 단위는 **역할 기반 포트폴리오 컴포넌트**
- 표시 단위는 **자산군**
- 현재 기본 자산군 카탈로그는 모두 대표 종목 역할이지만, 구조상 동일비중 바스켓/배당 보정 역할도 지원합니다
- 선택된 컴포넌트 조합은 화면의 `현재 적용된 ... 조합` 카드에서 확인할 수 있습니다

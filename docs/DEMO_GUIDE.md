# 데모 가이드

## 이 데모가 보여주는 것

이 서비스는 “섹터 후보군 관리 -> 대표 종목 선택 -> Efficient Frontier 계산” 흐름을 설명하는 데모입니다.

사용자는 메인 화면에서:

1. 위험 성향을 고릅니다.
2. 시스템은 active 유니버스의 섹터 후보군에서 대표 종목 1개씩을 선택합니다.
3. 선택된 대표 종목 유니버스로 Efficient Frontier를 계산합니다.
   이때 계산과 히스토리 차트는 가장 늦게 시작한 종목 기준의 공통 가격 구간만 사용합니다.
4. 화면은 결과를 섹터 비중/리스크 기여도/설명 카드로 보여줍니다.

현재 메인 화면은 `위험 슬라이더`만 노출하며, 투자 기간과 직접 목표 변동성 입력은 숨겨져 있습니다.

## 발표할 때 핵심 메시지

- "이 서비스는 종목 추천 서비스가 아니라 포트폴리오 구조를 설명하는 시뮬레이션입니다."
- "관리자가 섹터별 후보 종목군을 정하면, 시스템은 섹터당 대표 종목 1개씩을 선택해 최적화를 수행합니다."
- "대표 종목 선택은 Sharpe Ratio와 상관관계 제약을 함께 고려합니다."
- "화면은 계산 결과를 섹터 기준으로 다시 묶어 보여주기 때문에, 기술적으로는 종목 최적화지만 사용자에겐 섹터 구조로 설명됩니다."

## 시연 순서 추천

### 1. 관리자 콘솔 준비

`/admin`에서 아래를 먼저 보여주면 좋습니다.

- active 유니버스 존재
- 가격 적재 성공
- readiness `계산 가능`

### 2. 메인 시뮬레이터

메인 `/`에서는 아래 순서로 설명하면 자연스럽습니다.

1. 위험 성향 선택
2. Efficient Frontier 차트
3. 현재 포트폴리오 포인트
4. 현재 적용된 대표 종목 조합
5. 섹터별 비중과 리스크 기여도
6. 설명 카드

## 추천 입력값

### 안정형

```json
{
  "risk_profile": "conservative",
  "investment_horizon": "medium"
}
```

### 균형형

```json
{
  "risk_profile": "balanced",
  "investment_horizon": "medium"
}
```

### 성장형

```json
{
  "risk_profile": "growth",
  "investment_horizon": "medium"
}
```

## 시연 전 체크리스트

- `/health`가 `{"status":"ok"}` 를 반환하는지 확인
- `/admin/universe/status`에서 active 버전이 잡혀 있는지 확인
- `/admin/universe/readiness`에서 `ready=true`인지 확인
- `/admin/prices/status`에서 최근 가격 적재가 성공했는지 확인
- 메인 페이지에서 차트와 카드가 정상 렌더링되는지 확인
- 슬라이더를 움직였을 때 포트폴리오 포인트가 바뀌는지 확인

## 관리자 콘솔 운영 순서

1. 섹터별 후보 종목 입력
2. 유니버스 버전 생성 또는 수정
3. 필요한 버전을 active로 전환
4. 가격 갱신 실행
5. readiness 점검
6. 메인 시뮬레이터에서 결과 확인

## 지금 이 데모를 볼 때 알아야 하는 점

- 계산 단위는 **대표 종목**
- 표시 단위는 **섹터**
- 현재는 섹터별 대표 종목이 1개씩 선택됩니다
- 선택된 대표 종목 조합은 화면의 `현재 적용된 대표 종목 조합` 카드에서 확인할 수 있습니다
